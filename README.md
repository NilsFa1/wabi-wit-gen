## Lizenz

[Apache-2.0](LICENSE), siehe auch [NOTICE](NOTICE). Ausnahme:
`client-sdk/packages/pki/core-go` steht unter EUPL-1.2, weil der Core auf gematik
gempki aufbaut. Vom Generator erzeugter Code (inkl. der mitkopierten Runtimes)
gehört dem, der den Generator ausführt, und ist unter beliebiger Lizenz nutzbar.
